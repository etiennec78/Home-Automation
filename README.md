# Home Automation 🏡

Welcome to my home automation repository !

Here you will find various Home Assistant related projects and blueprints I use everyday in my own house !

## How to use 🔌

To implement any of them in your home, you'll have to [install Home Assistant](https://www.home-assistant.io/installation/) and follow README instructions

* Some of these projects require sensors. You can find more information on how to set them up in [sensors.md](sensors.md)
* Each project is made to work with third-party devices. e.g.: You don't need the ESPHome Gate Firmware to use the Automatic Gate
